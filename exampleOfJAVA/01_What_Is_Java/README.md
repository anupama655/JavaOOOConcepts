# 01 What Is Java

This example introduces Java, its purpose, and why it is a popular language for building platform-independent applications.

## Files
- `WhatIsJava.java`
- `output.txt`

## Run
```bash
javac WhatIsJava.java
java WhatIsJava
```

## Concept
Focus on the Java language, the Java Virtual Machine, and how Java programs are compiled and run consistently across platforms.
