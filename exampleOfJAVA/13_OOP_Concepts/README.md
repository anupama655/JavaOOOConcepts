# 13 OOP Concepts

This example provides a practical overview of key Object-Oriented Programming concepts used in Java.

## Files
- `OOPConcepts.java`
- `output.txt`

## Run
```bash
javac OOPConcepts.java
java OOPConcepts
```

## Concept
Review the building blocks of OOP, including classes, objects, abstraction, inheritance, polymorphism, and encapsulation.
