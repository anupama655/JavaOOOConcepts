## Interview preparation checklist

Before interviews, focus on these points:

- Java basics: syntax, data types, variables, operators
- OOP pillars: encapsulation, inheritance, polymorphism, abstraction
- Java memory model: stack vs heap
- String handling and immutability
- Collections: ArrayList, HashSet, HashMap
- Exception handling: checked vs unchecked exceptions
- Multithreading basics: thread lifecycle and synchronization
- Java architecture: JDK, JRE, JVM

## Sample interview answer starters

### Encapsulation
"Encapsulation is the process of binding data and methods together and restricting direct access. It helps protect data and maintain clean, secure object design."

### Inheritance
"Inheritance allows one class to reuse the features of another class, helping reduce code duplication and encourage hierarchical design."

### Polymorphism
"Polymorphism means one interface or method can behave differently based on the object type, which improves flexibility and extensibility."

### Exception Handling
"Exception handling is used to catch runtime errors and respond gracefully without crashing the application."
