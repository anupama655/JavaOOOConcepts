# 02 Java Architecture

This program explains the basic structure of Java architecture, including how source code is compiled and executed using the JDK/JRE/JVM model.

## Files
- `JavaArchitecture.java`
- `output.txt`

## Run
```bash
javac JavaArchitecture.java
java JavaArchitecture
```

## Concept
Learn how Java source code is translated into bytecode and run by the JVM, which is the core reason Java is platform independent.
