# 12 This Keyword

This example explains the `this` keyword in Java and how it refers to the current instance of a class.

## Files
- `ThisKeywordExample.java`
- `output.txt`

## Run
```bash
javac ThisKeywordExample.java
java ThisKeywordExample
```

## Concept
Understand how `this` is used to distinguish instance variables from parameters and refer to the current object clearly.
