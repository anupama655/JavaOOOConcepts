# 15 Encapsulation

This example demonstrates encapsulation by hiding data inside a class and exposing it through controlled methods.

## Files
- `EncapsulationExample.java`
- `output.txt`

## Run
```bash
javac EncapsulationExample.java
java EncapsulationExample
```

## Concept
Use access modifiers and getter/setter methods to secure data and protect the integrity of an object's internal state.
