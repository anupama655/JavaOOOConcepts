# 03 Basic Program

This example demonstrates the simplest structure of a Java program, including the class declaration, `main` method, and console output.

## Files
- `BasicProgram.java`
- `output.txt`

## Run
```bash
javac BasicProgram.java
java BasicProgram
```

## Concept
Understand the minimum required components of a Java application and how execution begins from the `main` method.
