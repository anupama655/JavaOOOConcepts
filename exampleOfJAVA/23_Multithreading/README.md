# 23 Multithreading

This example introduces multi-threading, where multiple tasks can run concurrently within a Java program.

## Files
- `MultithreadingExample.java`
- `output.txt`

## Run
```bash
javac MultithreadingExample.java
java MultithreadingExample
```

## Concept
Learn how threads work, how they share resources, and why concurrency is important for responsive and efficient programs.
