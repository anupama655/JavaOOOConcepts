# 22 Collections Framework

This example introduces Java's collection classes such as lists, sets, and maps, which are used to store and manage groups of objects.

## Files
- `CollectionsExample.java`
- `output.txt`

## Run
```bash
javac CollectionsExample.java
java CollectionsExample
```

## Concept
Understand how collections simplify data management and support common operations such as add, remove, search, and iteration.
